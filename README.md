# Toonflow Studio 本地客户端

参考局域网 Toonflow 界面制作的独立网页客户端。

## 启动

在此目录运行 `node server.js`，然后访问 http://127.0.0.1:7790/ 。需要 Node.js，无需安装依赖。

超分管理员密码可以在弹窗中输入；如需本机自动登录，可创建不纳入版本控制的 `local-config.js`，内容为 `window.TOONFLOW_UPSCALE_PASSWORD = '你的密码';`。该文件会被浏览器加载，仅用于可信的本地环境。

## 功能

- 新建、重命名、删除、导入和导出项目；数据保存在当前浏览器的 IndexedDB 中。首次打开会自动读取旧版 localStorage 项目，旧数据保留作为迁移备份。
- 画布支持添加文字、图片、视频和生成节点，拖动、连线、缩放、整理及删除节点。点击来源节点的“输出”再点击目标节点的“输入”创建连线；再次点击来源输出可取消，点击连线可以断开。图片可从本机导入。
- 文档可新建、编辑并自动保存。项目以 JSON 文件导出和导入；图片也包含在导出文件中。
- 在设置中配置兼容 OpenAI Chat Completions 的地址、模型和密钥后，助手可调用该接口。密钥保存在本机浏览器中；接口须允许浏览器跨域请求。
- 视频生成节点可提交任务到局域网 MiniMax-H3 网关（192.168.111.20:30011）。先添加一张图片素材，再添加视频生成节点并选择图片。客户端保存任务 ID，并每 5 秒查询状态；任务完成后画布节点与任务详情窗口均可播放、下载。支持一张参考图、4–15 秒、480p/768p、横屏/竖屏/方形画幅和 8/20/30/50 步。提交结果不明确时先在网关核对，客户端不会自动重试。
- 视频生成节点可选择“首尾帧生成”：将首帧和尾帧图片添加到画布后在生成窗口中分别选择，也可只指定其中一帧。服务端需要加载支持 FL2VA 的模型分支；如果服务端不支持，会显示其返回的错误。
- 对仅运行 ref2va 分支的服务，可尝试“首尾帧 + 参考图（当前服务，实验）”：使用 ref2va 请求发送首尾关键帧，并附带一张参考图。实际支持情况取决于服务端 SGLang 版本和部署配置；不可保证关键帧一定生效。
- 首页和工作区的“查询视频任务”支持按任务 ID 查询和自动刷新，完成后预览、下载，或将结果加入当前画布。
- 已完成的 H3 视频可从节点或任务详情中提取首帧、尾帧，生成图片节点并与视频节点连线。图片保存在浏览器本地存储中。
- 完成的 H3 视频节点支持通过网关 FlashVSR+ 发起 2 倍、2K 或 4K 超分；需要使用网关管理员密码登录，任务完成后可以预览和下载。超分任务等待 H3 空闲后执行。

这是独立实现，并非原项目的完整功能或数据格式。图片生成节点尚未接入生成服务。浏览器存储有容量限制，重要内容请定期导出备份；服务繁忙时请到网关检查队列。
